```

**场景：知乎问题"Flash Attention 和 SDPA 哪个快？"**
```
取决于平台和上下文。在 Orin 上实测，FA2 isolated kernel 反而比 cuDNN SDPA 慢（0.306ms vs 0.127ms），但全模型推理快 27%——因为 FA2 在 kernel 内部处理 causal mask，绕过了 HuggingFace 传 attention_mask 导致 SDPA 退化为 math backend 的问题。写了一篇详细的对比分析（含 NCU 硬件 counter 数据），在我主页。
```

**场景：知乎问题"具身智能/机器人大模型怎么部署？"**
```
正在做这个方向。核心观点：VLA 模型不是 chatbot，刷新率比单次精度更重要。实测 Orin 上 3B VLA 模型的 profiling 数据显示，算子已经逼近硬件极限（cuBLAS 带宽利用率 72%），真正的优化空间在系统层面（67% 框架空转、52280 次 kernel launch 调度延迟）。写了个五篇系列，从编译到 profiling 到 C++ 改造到量化，最后会开源一个端侧 AI OS。
